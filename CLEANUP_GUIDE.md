# MontaSpace v0.8.2 — Project cleanup guide

This is a **source-only copy** from the uploaded MontaSpace folder. No runtime Python or installer application logic was changed.

## Your existing development folder

Keep your existing `.git/` repository and `.venv/` virtual environment. Do **not** delete them.

You can delete these **generated**, rebuildable items after making a backup and verifying the installer/uninstaller:
- `build/` — PyInstaller temporary build artifacts
- `dist/` — bundled application output, reproducible via `build_windows.bat` or `build_installer.bat`
- `MontaSpace.spec` — generated by the current PyInstaller command (recreated automatically)

`installer-output/` contains the successful `MontaSpace_Setup_0.8.2.exe`. **Copy it to a safe release/archive location before removing this folder**. If you plan to retest the installer, keep it until testing is finished.

`docs/testing/` holds the three historical testing checklists moved from the root. No checklist content was changed.

## Rebuild

Use your existing `.venv` and installed NSIS 3.13, then run `build_installer.bat`. This regenerates `build/`, `dist/`, `MontaSpace.spec`, and `installer-output/`.

## Safe merge procedure

1. Back up your current Windows project folder and keep `.git/` and `.venv/` intact.
2. Copy the source files from this package into the existing project.
3. After checking the build, remove old *root-level* checklist files if desired (they are now in `docs/testing/`).
4. Do not commit generated folders, personal projects or the virtual environment.

The Windows uninstallation test was **not confirmed by the supplied ZIP**. Check that before finalizing/releasing v0.8.2.
